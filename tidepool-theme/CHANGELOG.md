# Changelog

## 1.0.0 - 2026-10-07

Initial release of **Tidepool**.

- Hand-tuned palette with its own hues, saturation and lightness
- Textce theme file (`.textcetheme`)
- VS Code color theme
- Sublime Text color scheme
- Neovim and Vim colorscheme
- Terminal schemes for Windows Terminal, iTerm2, Alacritty, kitty, WezTerm, Ghostty and X11
- CSS custom properties and Sass variables
